## 第一版工作范围

预训练使用固定快照的中英 Wikipedia，包含清洗、去重、文档划分、编码、采样和来源记录。本轮复用初版仅从原始 train 文档拟合的 32,000 词表 BPE，并校验相同 SHA256；中文在质量过滤、哈希、去重和编码前，使用固定官方 OpenCC C++ 绑定做可追溯的繁转简。新 train 的目标容量为中英文各至少 500M Token，构建上限各 550M；训练累计处理 1B Token，中英各约 500M。随机有放回取窗不保证完整覆盖这些语料位置。

旧英文验证/测试流校验后按字节复制；旧中文验证/测试从原文重建，核对旧 Token 身份，再按本轮简体规则重新编码。保护源 ID、原始文本和转换后文本哈希。旧 BPE 的 train-only 声明描述的是原始语料分区；繁转简可能合并历史 train/holdout 的不同文本，不能进一步声称新转换后的 holdout 文本从未影响旧 BPE 拟合。新旧中文评测文本和 Token 身份不同，Loss 不能直接横向比较。

模型采用因果注意力、GQA、RoPE、RMSNorm、SwiGLU。训练包含 AdamW、Warmup、Cosine Decay、梯度累积、梯度裁剪、BF16/FP16/FP32 路径、Activation Checkpointing、Checkpoint 和断点恢复。

Qwen 对照线在同一 Base 上比较全参数 SFT 和 LoRA SFT，再从明确选定的 SFT Checkpoint 开始 DPO。使用相同训练数据、模板、有效 Token 预算和等额调参预算；各自调整学习率。实现配置和数据校验不代表远程训练已经通过。

2026-10-26 后训练方案补充：用户同意先使用自研 300M 完成预训练到 SFT 的实验。首轮目标为 20,000 条训练、1,000 条验证、1,000 条独立测试，训练分区另取 2,000 条作 pilot；先用同一 Base 比较学习率，按验证结果决定后续训练轮数。中文统一简体，中英按回答监督 Token 接近平衡。已完成固定源、官方 OpenCC、过滤、分组、holdout 片段检查与发布；40 条 train/validation 分层 LLM 抽审又隔离 14 条疑点，最终为 19,991 train、995 validation、1,000 test、2,000 train 内 pilot，完整输入均不超过 512 Token。正式版本 `20261026_170531` 通过本地/远程复现与全量结构验收，64 项 CPU 测试通过，语义未全量由人工专家核验。尚未执行 SFT GPU 训练；来源和质量边界见 [SFT 数据构建](sft-data-build.md)。新增自研 SFT 的数据/模型接入必须保护已有预训练恢复身份，不能直接套用 MASSIVE 的 JSON 协议。

MoE、PPO、GRPO、分布式训练、7B QLoRA、Web 管理界面、调度平台和 FineWeb-Edu 混合数据放入后续扩展。500 元是总费用上限，不是完成全部对照实验的已验证报价。若实测费用不足以覆盖目标，应停止并记录范围调整，不能将少量基线标成 1B 完成，也不能用删去独立评测来换取更多训练。

## 验收要求

1. 先通过因果遮罩、目标错位、Loss Mask、梯度累积、数据隔离和恢复状态的正确性测试，再训练。
2. 恢复保存模型、优化器、调度器、随机数、数据进度和适用的精度状态。同环境、同配置下，恢复与连续训练应在预设容差内一致；跨 GPU 和依赖版本逐位相同不在承诺内。
3. 验证集负责调参和选模型；独立测试集只进入最终报告。观察测试结果后修改系统必须作为新一轮研究记录。
4. 记录数据版本/哈希、模型来源、代码版本、依赖、完整配置、种子、实际步数、有效 Token 数、显存、吞吐、时长、费用和停止原因。
5. 中英文指标分开报告。预训练报告 Loss/PPL；原 Qwen 结构化任务线报告意图准确率、槽位 F1、JSON 有效率、完整任务成功率。当前自研 300M 通用指令 SFT 先报告回答 Loss/PPL、固定预训练验证窗口及固定提示表现；后续按任务定义独立准确率，不能将 Loss 下降当作任务准确率提升。
6. 无提升和退化都是允许的结果；需要解释局限、数据构造影响与预算约束。

## 需要远程验证的内容

截至 2026-10-24，远程依赖、CUDA/BF16、100M 模型 GPU 工作和 20 步 Checkpoint 恢复已通过，原始配置及用户手动配置各完成一轮 1000 步基线。每轮约 16.384M 训练 Token 支持流程和初步学习曲线验收，不代表模型已充分预训练。完整后训练、GPU 连续/恢复数值对照与最终独立测试仍需分别验收。

本轮已确认 100M 累计训练 1B 有效 Token，后续再做独立 300M。首轮 `060038Z` 因真实单次 OpenCC 转换非幂等失败，未编码、未发布 manifest；修复后的 `060332Z` 后经受控 SIGINT 保留归档。最终 `runs/data_1b_prepare_20261024T062547Z` 已成功完成，正式 `artifacts/pretrain/wikipedia_1b/manifest.json` 通过 86 项独立验收（38.9358 秒）：train en 549,999,999、zh 549,999,984，合计 1,099,999,983 Token。六个 CPU 采样均为 `[2, 1024]`；英文 holdout 字节不变、中文新旧重建及保护源/原始/转换 hash 隔离通过。远程完整 CPU 回归为 215 passed in 9.71s，无跳过；历史失败与验收记录保留于 [verification.md](verification.md)。
