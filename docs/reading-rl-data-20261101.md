## SFT完成后仍要做

1. 用开发集检查新SFT的正确率、非零奖励命中、EOS停止与截断情况。严格别名匹配可能漏掉合理同义答案，不能把所有reward=0都直接认定为错误。
2. 用同一个选定SFT生成多个训练题候选，排除空答、截断、无关回答和重复，审查合理但未收录的答案别名；仅将可靠的低质量候选作为rejected。DPO偏好发布另建版本，绑定生成模型SHA256。
3. 对接并验证阅读任务的DPO/PPO/GRPO训练入口。已有数学奖励或外部模型配置不能直接冒充当前自研模型的阅读RL实现。
4. 三条路线分别从同一SFT起点初始化。每条只遍历一轮训练题；用户于2026-11-02明确允许PPO每批rollout做两次内部优化更新，GRPO iterations=1，不追加数据第二轮。
5. 最终对固定2,000题统一评测，报告中英分组EM、自定义F1、停止率及训练成本。

RLVR是奖励来源，可与PPO或GRPO组合。当前没有为了凑数伪造负例，也没有在SFT训练期间另起GPU作业抢占显存。
